# My Home Kitchen Remedies

Simple remedies people can make at home, each with:
- an honest evidence rating (Health-agency advice / Some research / Traditional use)
- who should be careful (babies, children, pregnancy, medicines, allergies) and when to see a doctor
- links to the official sources (NIH, CDC, FDA, AAD, AAO, Mayo Clinic)

Free: every remedy with its safety info. Premium (through CashCow): My Remedies, My Kitchen, shopping list.
One CashCow account works here and in the other CashCow apps.

Remedies live in `remedies.js`. Wording rule: never say a remedy treats, cures or prevents a disease.
Rebrand in `brand.js`.

## Render (Static Site)
- Build command: `npm install && npm run build`
- Publish directory: `dist`
